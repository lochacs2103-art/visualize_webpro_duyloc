# Pivot giữ lại và dùng cho file cùng cột

Ngày: 2026-11-18

Bảng pivot không tự mất khi mở lại cùng file: lần chạy gần nhất được ghi lại. Bấm Lưu pivot thì tên đó nằm trong danh sách của file.

File khác có đủ các cột đó sẽ thấy pivot này ở mục Dùng cho file cùng cột. Bấm vào là chạy lại trên dữ liệu của file mới. Mapping không đổi.
