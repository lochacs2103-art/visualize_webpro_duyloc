# Tính tổng cột tiền trên trang Mapping

Ngày: 2026-11-17

Bỏ nút Data Studio ở thư viện, file gần đây và trang xem file.

Trang Mapping có nút Tính tổng cạnh cột số. Bấm xong hiện tổng theo từng file (T10, T11, T12) và tổng cộng.

Project loc: đã nối Amount của T11 vào Số tiền. Tổng Số tiền: T11 16.570.000, T10 16.860.000, T12 2.450, cộng 33.432.450.
